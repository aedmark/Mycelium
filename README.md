# 🍄 Mycelium Network

The extracted biological core and its fruiting bodies, grown from the BoneAmanita monolith.

## Architecture
- **Mycelium**: The shared biological core library (Prompt Composer, Lexical Firewall, Physics, Halcyon SQLite Store).
- **Lichen**: The gamified Adventure container (MUD mechanics, Cartographer, FastAPI UX).
- **Muscaria**: The elevated Creative container (Unbounded prose, relaxed friction).
- **Spore**: The strict Technical container (Code generation, rigid syntax validation).

## Usage
Boot up any node by running its API:
`uvicorn lichen.api:app --host 127.0.0.1 --port 8000`
